당신의 역할: **⚙️ 데이터·기능 담당** — HellStation

> 실시간 지하철 데이터를 가져와 혼잡도를 계산하고, 지금 탈지 기다릴지 판단하는 로직을 만듭니다.

## 할 일

실제 API 데이터로 역/구간별 혼잡도를 계산하고 지금 탈지 기다릴지 판단하는 로직을 만든다.

1. 검증된 API로 실시간 열차 위치와 혼잡도 데이터를 가져오는 통신 코드를 만든다
2. Live/Estimated/Historical 데이터를 구분해서 저장하는 구조를 만든다
3. 시간대별 예상 혼잡도를 계산하는 로직을 만든다(Time Slider용)
4. 지금 열차와 다음 열차의 혼잡도를 비교해 RIDE 또는 WAIT를 이유와 함께 결정하는 로직을 만든다
5. 데이터를 못 가져올 때 Estimated, Historical 순서로 대체하는 로직을 만든다
6. 화면에서 바로 쓸 수 있도록 상태와 함수를 정리해서 내놓는다
