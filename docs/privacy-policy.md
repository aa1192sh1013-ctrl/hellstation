# HellStation 개인정보처리방침

**시행일: 2026-09-01**

## 한 줄로

**개인정보를 수집하지 않습니다.** 계정도, 위치도, 광고도, 분석 도구도 없습니다.

---

## 1. 수집하지 않는 것

- 이름·이메일·전화번호·생년월일 등 신원을 알 수 있는 정보
- **위치** — 위치 권한 자체를 요청하지 않습니다
- 연락처·사진·파일·기기 저장소
- 광고 식별자(AAID)
- 사용 기록, 화면 이동 기록, 충돌 보고

앱에는 **분석 도구도 광고 SDK도 들어 있지 않습니다.** 소스가 공개되어 있으므로 직접 확인하실 수 있습니다.

## 2. 요청하는 권한

| 권한 | 쓰는 이유 |
|---|---|
| `INTERNET` | 지하철 도착 정보와 역 목록을 받아오기 위해 |
| `ACCESS_NETWORK_STATE` | 연결이 끊겼을 때 그 사실을 화면에 알리기 위해 |

이 둘이 전부입니다. 다른 권한은 요청하지 않습니다.

## 3. 기기 안에만 저장되는 것

| 저장하는 것 | 왜 |
|---|---|
| 화면 설정(기기 설정/밝게/어둡게) | 다시 열었을 때 같은 모습으로 보여주기 위해 |
| 기본 방향(상행/하행) | 매번 같은 방향을 다시 고르지 않도록 |
| 즐겨찾는 역 | 자주 쓰는 역을 위에 올리기 위해 |
| 지하철 역 목록 캐시 | 신호가 끊긴 지하철 안에서도 지도가 뜨도록 |

**전부 기기 안에만 있습니다.** 어떤 서버로도 보내지 않으며, 앱을 삭제하면 함께 사라집니다.
HellStation은 **자체 서버를 운영하지 않습니다.**

## 4. 외부로 나가는 통신 — 알아 두셔야 할 것

역을 누르면 그 **역 이름**을 서울특별시 열린데이터광장에 보냅니다. 도착 정보를 받기 위해서입니다.

- **보내는 것:** 역 이름, 발급받은 인증키
- **보내지 않는 것:** 기기 식별자, 계정 정보, 위치, 사용 기록
- **보내는 곳:** `openapi.seoul.go.kr`, `swopenapi.seoul.go.kr` — **이 두 곳 외에는 어디와도 통신하지 않습니다** (앱의 네트워크 설정으로 나머지를 막아 두었습니다)

> ### ⚠️ 이 통신은 HTTPS가 아닙니다
>
> 서울시 열린데이터광장이 **HTTPS를 지원하지 않아** 암호화되지 않은 HTTP로 통신합니다.
> 따라서 같은 와이파이를 쓰는 사람이나 통신 경로 중간에서 **어느 역을 조회했는지 볼 수 있습니다.**
>
> 이름·계정 같은 정보는 오가지 않지만, "이 사람이 지금 어느 역을 보고 있다"는 사실은 드러납니다.
> 민감한 정보라고 보긴 어렵지만 **모르고 쓰시는 것보다 알고 쓰시는 편이 낫다고 판단해 적습니다.**
> 서울시가 HTTPS를 지원하면 즉시 바꾸겠습니다.

일반적인 인터넷 통신과 마찬가지로 서울시 서버에는 접속 기록(IP 등)이 남을 수 있습니다.
그 부분은 서울특별시의 개인정보 처리 방침을 따릅니다.

## 5. 제3자 제공·판매

**없습니다.** 4번의 서울시 공공 API 호출 외에 어떤 곳에도 데이터를 넘기지 않으며, 어떤 데이터도 판매하지 않습니다.

## 6. 보관 기간

서버에 보관하는 데이터가 없으므로 보관 기간이 없습니다.
기기 안의 설정과 캐시는 **사용자가 앱을 삭제할 때까지** 남습니다.

## 7. 삭제 방법

앱을 삭제하면 저장된 설정·즐겨찾기·캐시가 모두 지워집니다. **다른 곳에 사본이 없습니다.**

앱을 지우지 않고 비우려면: 설정 → 애플리케이션 → HellStation → 저장공간 → 데이터 삭제

## 8. 만 14세 미만 아동

아동을 대상으로 하지 않으며, 나이를 묻거나 아동의 개인정보를 따로 수집하지 않습니다.

## 9. 데이터 출처

이 앱이 보여주는 혼잡도와 도착 정보의 출처입니다.

- 서울교통공사 지하철혼잡도정보 — 공공누리 제3유형(출처표시 + 변경금지)
- 서울특별시 열린데이터광장 — 출처표시

## 10. 방침이 바뀌면

이 문서를 고치고 시행일을 갱신합니다. 변경 이력은 저장소의 커밋 기록에 그대로 남습니다.
